# Catch journal illustrations

Original illustrations made for Pacific Drift with Magnific (model: Google Nano Banana 2.1, 1k, 3:2), generated 31 October 2026 on the project owner's Magnific account. Two variants were generated per species and the more anatomically faithful one was chosen by eye against the species notes below. The albacore image (`jUM1cqKLD0`) was generated first and used as the style reference for the other fifteen, so the set reads as one natural-history series.

The game files are 1024 × 683 and 480 × 320 WebP, letterboxed on each image's own paper colour. Source JPEGs (1024 px, as delivered by Magnific) are kept outside the build in `work/fish-images/source/`.

Shared prompt frame (species text in the middle):

> Natural-history scientific illustration in gouache and watercolour on plain warm off-white paper, matching the reference's style: one adult **[species]** in an accurate side profile facing left, the whole fish in frame with generous margin. **[anatomy and colour notes]** Believable anatomy, true colours, soft even light, no shadow, no scenery, no text, no labels, no border.

The nine species above were added on 31 October 2026 with the same model, frame and albacore style reference.

These are artworks, not specimens. They are checked against general field-guide descriptions of each species, but small details (fin-ray counts, exact spot patterns, scute counts) should not be read as scientific reference.

Undiscovered species are shown as `<id>-silhouette.webp`: flat ink silhouettes derived from each illustration by `tools/make-fish-silhouettes.mjs` (paper flood-filled from the border, holes closed). `tools/prep-fish-images.mjs` rebuilds the 1024 and 480 px files from the sources.
